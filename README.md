# Cleansie

This is a slack bot that i built in order to serve the purpose of choosing a topic for the debates that we do in our hackclub slack what is essentially does is it asks you about the topic you wanna choose and then it stores the topics in a database essentially a supabase database . It also can help you clear the database when you want and also can help you for listing 3 random topics out of all the topics so that the topics are fairly chosen rather than being chosen paritially by someone

# /suggestions 
This is a command that can be used to suggest a topic that u want to be discussed in a debate and once you enter the topic then it can be added to database in the supabase table suggestions 

# /topics-please
This command can be used to list 3 topics randomly from all the topics present in the database and this is a really great feature if you want to choose three topics without and partiality from the database that has all the topics stored

# /clear
This command can be used to clear all the topics from the database once you have chosen the 3 topics so that the next time new topics can be choosed
